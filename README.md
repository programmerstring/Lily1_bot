# Lily1 Bot

🙏 Lily Song Downloader Bot

This is a Telegram bot that downloads audio and lyrics from YouTube songs.

Features:
- Download audio from YouTube
- Get lyrics (subtitles) in multiple languages, including Amharic
- Sends audio and lyrics directly in Telegram

How to use:
1. Open the bot in Telegram: [@lily_ss_downloader_bot](https://t.me/lily_ss_downloader_bot)
2. Send a YouTube link
3. Receive the audio and lyrics

Requirements (Python packages):
- python-telegram-bot
- yt-dlp
- nest_asyncio
- ffmpeg-python
- requests
